# 中文命令範例

以下命令需在具備 Comfy Cloud MCP 工具的對話使用。初次操作先查詢帳號和模板。

## 先檢查

> 檢查 Comfy Cloud MCP 是否連線，確認我的訂閱與點數狀態，找 MiniMax H3 官方文字生影片及圖片生影片模板，列出支援的比例、長度、聲音設定與可取得的費用資訊。不要提交生成；查不到費用請明說未知。

## 文字生影片

> 用我的 Comfy Cloud 帳號，使用 MiniMax H3。畫面是雨夜的台北街頭，一隻橘貓走過霓虹招牌，鏡頭緩慢跟拍，電影感。希望 16:9、約 5 秒、1 個版本，保留雨聲與腳步聲，不要配樂或旁白。先檢查模板能否支援，不要提交生成。

## 圖片生影片

> 使用我附上的照片，以 MiniMax H3 生成約 5 秒直式影片。人物輕微轉頭，鏡頭慢慢推近，盡量保留人物外貌與服裝，加上自然環境聲，先做一版。缺少素材或參數不支援時先告訴我，不要提交生成。

## 確認後執行

> 開始生成，使用剛才確認的模板和設定，只做 1 個版本，完成後下載影片並告訴我存放位置。

## 修改與比較

> 用上一版相同設定，保留人物，把鏡頭改成環繞，先告訴我要修改哪些參數。

> 使用已確認設定，再生成 2 個不同版本供我比較。

## 建立簡化操作頁

> 將已確認的 MiniMax H3 工作流程儲存到我的 Comfy Cloud，建立 App Mode，只顯示畫面描述、必要參考素材、可支援的長度與比例、聲音需求和影片輸出，給我操作頁連結。
